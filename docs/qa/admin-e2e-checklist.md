# 后台管理系统 · 端到端手工用例

对应需规 [admin-requirements.md](../admin-requirements.md) §8 验收标准第 5 条。

- 环境：`nest-service` (localhost:3000) + `admin` (localhost:5174)
- 账号：`superadmin / admin123456`（内置超管）
- 记录方式：执行后在「结果」列填 ✅ / ❌ + 备注

---

## 0. 前置准备

```bash
# 1. 数据库迁移到最新
cd nest-service && npm run migration:run

# 2. 启动后端
npm run start:dev

# 3. 启动前端
cd ../admin && pnpm install && pnpm dev
```

**1.8 / 1.10 的 curl 示例**

```bash

  -d '{"username":"test_viewer","password":"123456"}' | grep -o '"token":"[^"]*' | cut -d'"' -f4)

# 应返回 403
curl -i -X DELETE "http://localhost:3000/api/admin/wishes/1" -H "Token: $TOKEN"
```

## 附：遗留项处理情况

1. ✅ **小程序端已校验 `users.status`** — [user.service.ts](../../nest-service/src/modules/foodie-buddy/user/user.service.ts) 的 `wechatLogin` 命中已有用户时先判 `status !== 1`，抛 403「账号已被禁用，请联系管理员」；mobile 端 `refreshCurrentUser` 捕获该错误后清除本地用户缓存。
2. ✅ **角色权限已支持动态配置** — 已新增 `admin_role_permissions` 表，后台「系统管理 → 角色权限」页可对 operator/viewer 的权限码进行勾选调整；superadmin 固定全权限不可改。运行时取值来自数据库，缺失或损坏时回落到 [admin-permissions.ts](../../nest-service/src/modules/admin/admin-permissions.ts) 的 `DEFAULT_ROLE_PERMISSIONS`。
3. ⚠️ **admin Docker 镜像未在本机验证** — 开发机拉不通 Docker Hub（见 [deploy/cloud/README.md §3.1](../../deploy/cloud/README.md)），[Dockerfile](../../admin/Dockerfile) 需在云服务器上首次构建时验证。构建阶段已通过 `pnpm --filter @fantastic-admin/core-element-plus run build` 等价验证。
