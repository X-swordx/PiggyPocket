## 自走查清单

- [ ] 亮色/暗色
- [ ] 窄屏/宽屏，无横向滚动
- [ ] 键盘可操作
- [ ] 加载/空/错误态
- [ ] 没有硬编码颜色/尺寸，使用现有 token
- [ ] 每条 AC 有截图或测试记录

## 升级条件

出现以下任一情况，停止实现并升级为完整 spec：

- 必须新造组件，或现有组件拼不出来
- 出现理解卡没覆盖、会影响用户体验的选择
- 范围明显超出「改动范围」
- 需要新增表或改接口契约
