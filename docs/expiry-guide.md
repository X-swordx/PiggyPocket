# 到期管家 · 使用说明

食品、药品、化妆品、滤芯、卡券……家里什么时候到期，都可以记在这里。到了你设定的日子，微信会通知你。

## 一、进入方式

- 首页点「到期管家」卡片
- 或底部导航栏第二个图标

## 二、添加一件物品

在列表页点右下角的 **+** 按钮。

| 字段 | 是否必填 | 说明 |
| ---- | -------- | ---- |
| 物品图片 | 选填 | 点顶部区域，可拍照或从相册选（首次会先请你同意隐私协议）。不传图会用一个随机底色代替 |
| 物品名称 | **必填** | 建议写清楚，如「布洛芬缓释胶囊」。搜索时会用到 |
| 到期日期 | **必填** | 日期选择器 |
| 数量 | 选填 | 默认 1 |
| 提前提醒 | 选填 | 到期当天 / 提前 1、3、7、15、30 天，默认**提前 3 天** |
| 存放位置 | 选填 | 冷藏 / 冷冻 / 常温 / 收纳柜 / 其他，默认冷藏 |
| 分类 | 选填 | 食品饮料 / 药品 / 美妆护肤 / 日用品 / 宠物用品 / 滤芯耗材 / 卡券会员 / 证件保险 / 其他，默认食品饮料 |
| 备注 | 选填 | 会一起出现在微信提醒里 |

保存后会弹窗问你是否开启到期提醒，建议点「开启」（原因见第五节）。

## 三、看懂列表

列表按到期日从近到远排列，顶部三个页签：

- **全部** —— 所有物品
- **即将到期** —— 已进入提醒范围但还没过期的
- **已过期** —— 到期日已经过去的

每张卡片上的角标和圆点表示状态：

| 状态 | 颜色 | 含义 |
| ---- | ---- | ---- |
| 充足 | 绿色 | 距到期还早，没到提醒范围 |
| 即将到期 | 橙色 | 剩余天数已经小于等于你设的「提前提醒」天数 |
| 已过期 | 红色 | 到期日已过 |

右上角文字是精确天数：`3天后到期` / `今天到期` / `5天前过期`。

> 「即将到期」按每件物品自己的提醒设置算。设了「提前 30 天」的证件，还剩 20 天时就会显示即将到期；设了「到期当天」的牛奶，只有当天才会显示。

点任意卡片进入**物品详情**，可以看到完整信息（到期状态、提醒设置、存放位置、类别、备注），底部两个按钮：**修改物品**、**删除物品**。删除会二次确认。

## 四、搜索：可以用大白话

点页签栏右侧的放大镜图标，输入后按键盘上的「搜索」确认。

它不是简单的关键词匹配，而是理解意思去找：

- 搜「**感冒药**」→ 能找到放在药箱里的「布洛芬缓释胶囊」
- 搜「**炒菜调料**」→ 能找到「花生油」「生抽」
- 搜「**洗头发的**」→ 能找到「洗发水」
- 搜「**快过期的感冒药**」「**已经过期的**」「**刚买的**」→ 按到期状态帮你筛

清空输入框或再点一次放大镜，就回到普通列表。

## 五、微信到期提醒

**每天上午 9 点**，系统会检查你的物品，把进入提醒范围的推送给你。通知里包含物品名称、到期日期、存放位置、数量和备注，点通知可直接跳回到期管家。

### 关于授权次数

微信的规则是：**你授权一次，只能收到一条提醒**。所以：

- 每次保存物品后都会问你要不要开启，多点几次就多攒几条额度
- 额度用完时，列表页顶部会出现一条「开启微信提醒，物品到期前通知你」的提示，点「开启」即可续上；点右侧 × 可以本次先不管
- 同一天有多件物品到期时，只会推**最早到期的那一件**，通知里会写「另有 N 件物品也快到期了」，剩下的留到之后再提醒——这样不会一次把额度耗光

### 提醒过的物品会不会重复提醒

不会重复推送。但如果你**修改了到期日期或提前提醒天数**，这件物品会重新排队等待提醒。

## 六、常见问题

**为什么一直没收到提醒？**
先看列表页顶部有没有那条「开启微信提醒」的提示——有就说明额度是 0，点「开启」授权一次。另外注意提醒是每天上午 9 点统一发送。

**物品记多了会不会翻不到？**
用搜索，直接说你想找什么，不用记具体名字。

**吃完/用完了怎么办？**
进详情页删除即可，目前没有单独的「已用完」状态。
